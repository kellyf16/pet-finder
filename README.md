# Pet Finder Web App

A full-stack web application for reporting and finding lost pets.

## Tech Stack
- **Frontend:** React, TypeScript, Leaflet, Nominatim, ImgBB
- **Backend:** Python Flask, SQLite

## Features
- Report lost pets with photos and location
- Interactive map and list view with filtering by status and type
- Password-protected "mark as found" resolution
- Real-time UI updates

## Setup
1. Clone the repo
2. Frontend: `cd frontend && npm install && npm run dev`
3. Backend: `cd backend && python app.py`
